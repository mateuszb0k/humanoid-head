## 1. MEETING OBJECTIVES
The primary goals were to integrate the major structural modules (Head, Neck, and Stand), continue the software migration to Raspberry Pi, and establish a clear action plan for the project's second milestone.

## 2. MECHANICAL & HARDWARE INTEGRATION
* **Neck Redesign:** The upper neck section was redesigned and updated to improve structural stability and range of motion.
* **Full Assembly:** The head, neck, and stand have been physically joined into a single unit.
* **Wiring Issue:** A technical bottleneck was identified—the power supply cables are too short to reach from the base to the servo drivers located in the head.
    * **Action:** Patryk is assigned to extend the wiring harness.
* **Jaw Stress Test:** We are preparing a test to verify if a single servo has enough torque to reliably operate the jaw mechanism in its final configuration.

## 3. SOFTWARE MIGRATION
* **Arduino to Raspberry Pi:** The conversion of the core control logic to the Raspberry Pi platform is ongoing. The team is focusing on ensuring I2C communication stability with the PWM drivers.

## 4. MILESTONE 2 ACTION PLAN
The team established the following 11-point roadmap for the upcoming phase:
1. **Face Tracking:** Implement real-time facial recognition and tracking.
2. **Lip Sync:** Synchronize jaw movement with speech patterns.
3. **Pi Code Verification:** Final validation of the control scripts on the Raspberry Pi.
4. **Microphone Integration:** Install and configure the audio input module.
5. **Camera Integration:** Mount and calibrate the visual sensor.
6. **PIR Sensor:** Add a Passive Infrared sensor for motion detection.
7. **Speaker Integration:** Install and test audio output.
8. **Wiring Extension:** Patryk to finalize the elongated cable management.
9. **System Synthesis:** Integrate hardware modules with the broader project ecosystem.
10. **Jaw Torque Test:** Practical verification of jaw servo performance.
11. **Mechanical Refinement:** Perform final corrections on 3D-printed mechanical parts.
