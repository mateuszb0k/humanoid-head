# Repository Structure: Hardware Module

This document provides a detailed overview of the directory structure and the contents of this repository.

## Directory Descriptions

### 3Dmodel
Contains the complete mechanical design and 3D assets for the robot's head assembly.
- **Photos**: A collection of images documenting the physical fabrication process, including both successful components and failed print attempts for reference.
- **Base**: Includes 3D models of electronic components (e.g., NVIDIA Jetson Nano) and the structural design of the robot's base.
- **head stl**: Contains individual .stl files for every component of the robot's head, optimized for 3D printing.
- **printing_progress.md**: A tracking file used to document the status and timeline of the 3D printing process for various parts.

### Code
Stores source code and scripts used during the development phase.
- Includes test scripts and firmware developed for Arduino and Raspberry Pi platforms to validate hardware functionality.

### DescServos
Dedicated to the robot's actuation system.
- Provides visual representations of servo placement within the assembly.
- Contains indexing and detailed descriptions mapping each servo to its specific anatomical movement or functional responsibility.

### Raports
A repository for documentation related to project management.
- Includes meeting minutes and formal progress reports generated by the hardware development team.
