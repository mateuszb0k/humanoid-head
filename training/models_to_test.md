\# Models to Test (Image Generation)



A curated list of next-generation image generation models to evaluate and compare within the project:



\## 1. Hunyuan Image 3.0

\*   \*\*Provider:\*\* Tencent

\*   \*\*Type:\*\* Open-source (Autoregressive MoE, 80B parameters)

\*   \*\*Key Features:\*\* Excellent comprehension of highly complex, long-form prompts. Strong balance between photorealism and semantic accuracy.

\*   \*\*Testing Method:\*\* Local deployment (Hugging Face / `diffusers`) or dedicated API.



\## 2. Flux 2 Max

\*   \*\*Provider:\*\* Black Forest Labs

\*   \*\*Type:\*\* Commercial API / Closed-source

\*   \*\*Key Features:\*\* Flagship quality, superior character consistency, ultra-photorealism, and exceptional text rendering capabilities.

\*   \*\*Testing Method:\*\* External APIs (e.g., Fal.ai, Replicate).



\## 3. Qwen-Image-2.0-Pro

\*   \*\*Provider:\*\* Alibaba Cloud

\*   \*\*Type:\*\* Commercial API

\*   \*\*Key Features:\*\* Unified generation and editing capabilities operating in native 2K resolution. Outstanding performance with text rendering, infographics, and poster design.

\*   \*\*Testing Method:\*\* Multi-provider APIs (e.g., Together AI).



\## 4. Reve V1.5

\*   \*\*Provider:\*\* Reve Image

\*   \*\*Type:\*\* Commercial API / Closed-source

\*   \*\*Key Features:\*\* Generates images directly in native 4K pixel space without relying on latent autoencoder compression. Exceptional lighting, intricate textures, and highly rated in current benchmarks.

\*   \*\*Testing Method:\*\* Dedicated Reve platform API.
