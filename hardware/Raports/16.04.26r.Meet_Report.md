## 1. MEETING OBJECTIVES
The focus was on improving fastener reliability in moving parts, finalized the software implementation of facial expressions, and initiated the transition to a Raspberry Pi-based control system.

## 2. MECHANICAL ADJUSTMENTS
* **Eyebrows:** Successfully replaced standard nuts with **nylon-insert lock nuts (Nyloc)** to prevent loosening during movement.
* **Lips:** A direct nut replacement was not possible as the existing nuts were heat-set into the 3D-printed parts during assembly.
    * **Proposed Fix:** The team will apply thread-locking fluid to these specific points to secure the fasteners without redesigning the parts.
* **Base/Stand Design:** Continued work on the head stand, specifically focusing on the internal layout and placement of electronics.

## 3. SOFTWARE & SYSTEM INTEGRATION
* **Emotional Expressions:** Completed the development of code functions for all required emotional states. Each expression is now mapped to specific servo configurations.
* **Platform Migration:** Work has begun on converting the existing control logic from Arduino to **Raspberry Pi**. This shift aims to provide more processing power for future high-level tasks.
* **Component Layout:** We started designing the arrangement of the Raspberry Pi, drivers, and power modules within the upcoming base unit.

## 4. NEXT STEPS
* **Threadlocker Application:** Apply the thread-locking adhesive to the lip mechanisms.
* **Code Testing on Pi:** Verify that the servo control functions via Raspberry Pi (GPIO/I2C) maintain the same precision as the previous Arduino setup.
* **Finalizing the Base:** Complete the CAD model of the stand with the confirmed component layout.
